Cine Las Vías

Un git push --force a deshoras ha destrozado la magnífica web del Cine las Vías: los selectores apuntan donde no deben, todo está descolocado y las clases son un caos. Vuestro equipo tiene que repararla. Cada prueba superada os da una pieza de la contraseña que desbloquea la salida.

  1. Francotiradores de selectores~10 min
  2. Recoloca la escena (position)~17 min
  3. Inspectores BEM~12 min
  • Cuantos menos intentos, más puntos. Las pistas cuestan puntos.
  • En la prueba 2 está prohibido usar flex y grid.
  • Podéis usar vuestros apuntes y MDN. Abrir el código fuente de esta web es trampa.
  • Si se acaba el tiempo, en la pestaña Salida tenéis vuestro código de puntuación para el profe.
